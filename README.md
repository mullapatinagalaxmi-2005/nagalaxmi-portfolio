# Mullapati Nagalaxmi — Minimal Developer Portfolio

A clean, responsive, photo-free personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — layout, typography, colors and responsive styling
- `script.js` — mobile navigation and current year

## Run locally
Open this folder in VS Code, then open `index.html` with the Live Server extension.

## Customize before publishing
Search in `index.html` and replace:
- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN`
- `YOUR_EMAIL@example.com`
- `YOUR_REPOSITORY` (use the direct repository URL for each project)

Add your resume PDF at `assets/resume.pdf`. If you do not want a resume download link yet, remove the Download resume button.

Review project descriptions and link only repositories that are public and ready for recruiters.

## GitHub Pages
1. Create a public repository named `nagalaxmi-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then save.
5. Wait for the published URL to appear in the Pages section.
